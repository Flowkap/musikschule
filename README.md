# Musikschule Gaby Kappes

Single-page website of Musikschule Gaby Kappes (singing lessons and woodwind instruments in Bernkastel-Kues), served via GitHub Pages at <https://gabykappes.de>.

- `index.html` – the whole site (inline CSS/JS, no build step, no external requests)
- `assets/img/` – logo, favicons and web-sized photos, named `<photo>-<width>x<height>.jpg`
- `assets/img/originals/` – full-resolution originals the web sizes are generated from

Open `index.html` locally in a browser to preview.
